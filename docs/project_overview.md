# Project Overview

## The Customer Exit — Telecom Analytics

**Author:** Cyril James Lunzaga

The Customer Exit is a large end-to-end telecom customer churn analytics case study based on the IBM Telco Customer Churn sample dataset.

The project combines:

- data-quality validation
- exploratory data analysis
- feature engineering
- customer segmentation
- statistical analysis
- visualization
- automated testing
- reproducible reporting
- business interpretation

## Dataset Scope

The validated analytical population contains:

- 7,043 customers
- 21 original variables
- 1,869 churned customers
- 5,174 retained customers
- 26.54% overall observed churn

## Analytical Principle

The project does not prioritize customer groups using churn percentage alone.

Interpretation also considers churn volume, segment size, monthly-charge exposure, effect size, confidence intervals, and business relevance.

The analysis is descriptive and observational and does not claim causal relationships.
